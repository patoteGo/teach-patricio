2AGENTS.md — a alavanca primáriaAGENTS.md — the primary lever

O Pi carrega o AGENTS.md (ou CLAUDE.md) na inicialização a partir de três lugares — e concatena toda correspondência no prompt de sistema.Pi loads AGENTS.md (or CLAUDE.md) at startup from three places — and concatenates every match into the system prompt.

Concatenar, não sobrescrever. Diferente das settings, múltiplos arquivos AGENTS.md se empilham. Ponha estilo compartilhado no global, convenções do repo na raiz do repo, e peculiaridades de módulo em subdiretórios — tudo compõe. Desative tudo com --no-context-files (-nc).Concatenate, not override. Unlike settings, multiple AGENTS.md files stack. Put shared style globally, repo conventions at the repo root, and module quirks in subdirs — all compose. Disable everything with --no-context-files (-nc).

3O prompt de sistema — substituir vs adicionarThe system prompt — replace vs append

Para quando o AGENTS.md não é suficiente e você precisa mudar como o Pi instrui o modelo, não apenas adicionar contexto.For when AGENTS.md isn't enough and you need to change how Pi instructs the model, not just add context.

🔴 SYSTEM.md — substituir🔴 SYSTEM.md — replace

.pi/SYSTEM.md (projeto) ou ~/.pi/agent/SYSTEM.md (global). Joga fora o prompt de sistema padrão do Pi. Arquivos de contexto + skills ainda são anexados..pi/SYSTEM.md (project) or ~/.pi/agent/SYSTEM.md (global). Throws away Pi's default system prompt. Context files + skills are still appended.

Use apenas se você realmente precisa de um persona customizado ou guardrails rígidos.Use only if you genuinely need a custom persona or strict guardrails.

🟢 APPEND_SYSTEM.md — estender🟢 APPEND_SYSTEM.md — extend

APPEND_SYSTEM.md adiciona ao prompt padrão sem substituí-lo. O padrão seguro para regras extras.APPEND_SYSTEM.md adds to the default prompt without replacing it. The safe default for extra rules.

Equivalentes de CLI: --system-prompt "…" / --append-system-prompt "…".CLI equivalents: --system-prompt "…" / --append-system-prompt "…".

Padrão: adicionar. Substituir o prompt de sistema descarta os padrões cuidadosos do Pi — recorra a isso apenas quando tiver um motivo específico. Nove em cada dez vezes, AGENTS.md + APPEND_SYSTEM.md é o par certo.Default to append. Replacing the system prompt discards Pi's careful defaults — reach for it only when you have a specific reason. Nine times out of ten, AGENTS.md + APPEND_SYSTEM.md is the right pair.

4settings.json — projeto sobrescreve globalsettings.json — project overrides global

Onde o AGENTS.md é conteúdo para o modelo, as settings são comportamento para o Pi. Dois arquivos, uma regra: projeto vence, objetos aninhados são mesclados.Where AGENTS.md is content for the model, settings are behavior for Pi. Two files, one rule: project wins, nested objects merge.

5Confiança — a fronteira de segurançaTrust — the security boundary

Qualquer coisa em .pi/ pode rodar código (extensões executam; skills podem instruir o modelo a fazer qualquer coisa). Então o Pi protege os recursos locais do projeto atrás de uma decisão de confiança.Anything in .pi/ can run code (extensions execute; skills can instruct the model to do anything). So Pi gates project-local resources behind a trust decision.

InterativoInteractive

Na inicialização, o Pi pergunta antes de carregar o .pi/ de uma pasta sem decisão salva. Salve sua resposta com /trust → escreve ~/.pi/agent/trust.json (reinicie para aplicar).On startup, Pi asks before loading .pi/ for a folder with no saved decision. Save your answer with /trust → writes ~/.pi/agent/trust.json (restart to apply).

Não-interativoNon-interactive

-p / --mode json / rpc não conseguem perguntar, então recorrem a defaultProjectTrust: "ask" (padrão) · "always" · "never". Sobrescreva uma execução com -a / -na.-p / --mode json / rpc can't prompt, so they fall back to defaultProjectTrust: "ask" (default) · "always" · "never". Override one run with -a / -na.

Por que importa: .pi/extensions/*.ts e packages instalados rodam com suas permissões completas. O prompt de confiança é a única barreira entre "eu clonei um repo" e "código arbitrário acabou de rodar." Revise extensões locais do projeto antes de confiar — mesma higiene que npm install.Why it matters: .pi/extensions/*.ts and installed packages run with your full permissions. The trust prompt is the one gate between "I cloned a repo" and "arbitrary code just ran." Review project-local extensions before trusting — same hygiene as npm install.

6Starter de copiar e colarCopy-paste starter

Solte estes dois arquivos num repo e o Pi se comporta melhor imediatamente — sem extensões, sem packages.Drop these two files in a repo and Pi immediately behaves better — no extensions, no packages. 

# .pi/settings.json
{
  "defaultThinkingLevel": "medium",
  "enabledModels": ["claude-sonnet-*", "gpt-4o"],
  "treeFilterMode": "labeled-only",
  "doubleEscapeAction": "tree",
  "compaction": { "keepRecentTokens": 24000 }
}
# + um AGENTS.md na raiz do repo (veja o template da §2)# + an AGENTS.md at the repo root (see §2 template)

Faça commit dos dois. AGENTS.md + .pi/settings.json no repo significa que o Pi de todo companheiro de equipe (e o seu noutra máquina) começa idêntico. Isso é configuração-como-documentação.Commit both. AGENTS.md + .pi/settings.json in the repo means every teammate's Pi (and yours on another machine) starts identical. That's configuration-as-documentation.
