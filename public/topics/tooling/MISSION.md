# Mission: Tooling

## Why

Turn everyday developer tools into reliable habits so editing and navigating code requires less conscious effort. Start with Vim's smallest useful command set and build it through short, repeatable practice.

## Success looks like

- Open a file in Vim, move, insert, delete, undo, save, and exit without getting stuck.
- Recall core commands from the editing goal rather than from a cheat sheet.
- Build new tool skills with a short daily drill instead of trying to memorize everything at once.

## Constraints

- Short, graphical, bilingual lessons with immediate hands-on feedback.
- Prefer built-in tutorials and official documentation over new apps or plugins.
- Teach only the commands needed for the next practical win.

## Out of scope

- Vim configuration, plugins, macros, registers, and editor customization until the core loop is automatic.
