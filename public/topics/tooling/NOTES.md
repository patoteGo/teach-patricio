# Teaching Notes — Tooling

- Experienced software developer building automatic command-line and editor habits.
- Skip editor history and configuration; emphasize a tiny operational loop and deliberate repetition.

## Stated preferences

- Tooling should be its own hub section, separate from interviews and software concepts.
- Start with basic Vim commands and a practical way to build muscle memory.

- Use `h2.section` for persisted completion checkpoints.
- Put one recall-worthy phrase in `<strong>` per teaching paragraph.
- Prefer practice in the real tool for immediate feedback; do not simulate Vim in JavaScript.
- Keep learner-facing labels bilingual in Portuguese and English.
