1A regra de uma fraseThe one-sentence rule

Nível = número de componentes assíncronos + número de restrições difíceis. Nível 1 = um cliente, uma API, um banco. Nível 2 = adiciona fila/email/cache. Nível 4 = adiciona concorrência em um único valor (leilão) ou ordem global.Level = number of async components + number of hard constraints. Level 1 = one client, one API, one database. Level 2 = add a queue/email/cache. Level 4 = add contention on a single value (auction) or global ordering.
