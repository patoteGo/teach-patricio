# Mission: Practical software concepts

## Why

Build interview-ready mental models for foundational software concepts, starting with SQL and
OAuth. The goal is to explain each concept clearly, recognize it in real systems, and solve a
small practical problem without relying on memorized jargon.

## Success looks like

- Read and write basic SQL using SELECT, WHERE, JOIN, GROUP BY, and aggregate functions.
- Explain the OAuth authorization-code flow, each participant, and why PKCE protects the code.
- Describe both concepts visually and answer common interview follow-ups in plain English.

## Constraints

- Short, graphical, bilingual lessons with immediate interactive feedback.
- Teach durable mental models before syntax details.
- Use primary specifications and official documentation for factual claims.

## Out of scope

- Database administration, query-plan tuning, advanced SQL, and vendor-specific syntax.
- Implementing an authorization server or covering every OAuth grant and extension.
