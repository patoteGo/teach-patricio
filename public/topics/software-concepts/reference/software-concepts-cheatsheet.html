SELECT c.name, COUNT(*) AS orders, SUM(o.total) AS revenue
FROM customers c
JOIN orders o ON o.customer_id = c.id
WHERE o.status = 'paid'
GROUP BY c.id, c.name
HAVING COUNT(*) > 1
ORDER BY revenue DESC;

API
  1. Redirect: o cliente envia o usuário ao servidor de autorização com escopo, state e desafio PKCE.client sends user to authorization server with scope, state, and PKCE challenge.
  2. Consent: o usuário se autentica ali e concede acesso.user authenticates there and grants access.
  3. Callback: o cliente recebe um código de autorização de curta duração.client receives a short-lived authorization code.
  4. Exchange: o cliente envia código + verifier PKCE ao endpoint de token.client sends code + PKCE verifier to token endpoint.
  5. API: o cliente envia o access token com escopo ao servidor de recursos.client sends scoped access token to resource server.
