# Software Company Resources

Fontes de alta confiança, anotadas. Conhecimento para as lições sai daqui —
não de "achismos". Sabedoria vem das comunidades. **TudoPT/EN** conforme o
hub. Mantenha enxuto: melhores que muitos.

## Knowledge

### Fundamentos web (independente de stack)

- [MDN — Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development)
  O padrão-ouro de HTML/CSS/JS/HTTP. **Use para:** toda pergunta "como a web
  funciona de verdade". Citar nas primeiras lições.
- [GitHub — Getting started with Git](https://docs.github.com/en/get-started/learning-to-code/getting-started-with-git)
  **Use para:** a lacuna de Git (ela é básica). Fluxo add/commit/push.

### Stack — TS + Next.js + Tailwind + Supabase + Vercel (lockado)

Princípio: ensinar o stack mais comum; pivotar só por necessidade/requisito de
cliente.

- [Next.js — Learn](https://nextjs.org/learn) — framework + modelo mental de
  rota/deploy.
- [Supabase docs](https://supabase.com/docs) — Postgres + auth + storage sem
  backend feito à mão (free tier).
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  **Use para:** ponte do C# (tipagem estática) para o TS.
- [Vercel — Deploy](https://vercel.com/docs/getting-started) **Use para:** "git
  push → no ar". Mata a lacuna "nunca publiquei" na lição 1.

### Usar IA no fluxo de dev (meta da missão)

- [Cursor — Agent docs](https://docs.cursor.com/agent)
  **Use para:** IA como par-programador; contexto, regras, prompt efetivo.
- [GitHub Copilot — Best practices](https://docs.github.com/en/copilot/get-started/best-practices)
  **Use para:** padrões seguros e eficazes de prompt.
- [Claude Code — Permission modes](https://code.claude.com/docs/en/permission-modes)
  **Use para:** limites de segurança quando a IA executa comandos.

### Negócio — encontrar e validar o 1º cliente (a investigação sem resposta)

- [_The Mom Test_ — Rob Fitzpatrick](https://www.momtestbook.com/)
  O livro canônico sobre **entrevistas com cliente que extraem verdade**, não
  gentileza. **Use para:** como falar com prospectos para aprender _o que_
  construir/vender (a pergunta Q6 sem resposta).
- [SBA — Market research & competitive analysis](https://www.sba.gov/business-guide/plan-your-business/market-research-competitive-analysis)
  **Use para:** a investigação estruturada "o quê / para quem / onde vender".

### Negócio — sabedoria de empresa de software bootstrapped

- [Startups for the Rest of Us — Rob Walling](https://www.startupsfortherestofus.com/)
  Podcast/sabedoria para software bootstrapped (não-VC). **Use para:** o
  caminho "stair-step" de serviços → produtos, pricing, packaging.
- [MicroConf](https://microconf.com/)
  Comunidade + conteúdo para fundadores bootstrapped. **Use para:** histórias
  reais e playbooks de quem cresceu devagar e no lucro.

## Wisdom (Communities)

- [99Freelas](https://99freelas.com.br/) — plataforma 100% brasileira, curva
  mais fácil para começar. **Use para:** primeiros clientes reais no Brasil.
- Workana — plataforma LatAm, clientes médios/maiores. **Use para:** quando
  estiver pronta para projetos maiores.
