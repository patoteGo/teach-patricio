# 0001 — Topic foundation: accuracy, not vocabulary

## Context

User requested a Portuguese topic. Already speaks PT (lives in Brazil),
dreams of native-like fluency. Named blocker: Spanish interference —
"too similar, too many false positives."

## Decision

Frame the topic as **contrastive ES→PT accuracy training**, not a
Portuguese course. The user does not need to acquire Portuguese; they need
to (1) notice where Spanish silently supplies wrong answers and (2) retrain
those reflexes.

Key grounding: immersion alone fossilizes interference because Brazilians
accommodate portuñol ("acomodação consentida", Rojas/UnB 2006). The lessons
must supply the correction loop daily life won't.

## Zone of proximal development

- Comprehension: high. Vocabulary: broad. Error awareness: low — the traps
  are invisible, which is why they survive.
- Lesson 0001 = falsos amigos (highest-frequency daily traps). Chosen over
  phonetics because vocabulary traps are immediately testable in-browser with
  instant feedback.

## What comes next (candidates, in ZPD order)

1. More falsos amigos tiers (restaurant/work/social situations).
2. Tá Falado pronunciation arc: vowel reduction + open/closed vowels —
   the single biggest "sounds like a foreigner" marker.
3. Grammar interference: gerúndio (estou comendo, never "estou a comer"),
   pronoun placement (me lembro, not "lembro-me" in speech), ser/estar edges.

## Revision triggers

- If user reports quiz items feel trivial → skip to phonetics arc.
- If user reports daily-life wins (caught own error) → log it, space the
  review to 1 week.
