2How it's organized

One folder per topic. Each topic is a standard teaching workspace — fully portable on its own.

teach-patricio/ ├── index.html # you are here — graphical hub ├── README.md # catalog auto-synced from topics/*/ └── topics/ # ONE FOLDER PER TOPIC ├── pi/ # the Pi power-user course │ ├── MISSION.md RESOURCES.md NOTES.md │ ├── assets/style.css │ ├── lessons/ reference/ learning-records/ └── _template/ # copy-and-go skeleton (CI skips it)

3Add a new topic

One command, then edit the mission and drop in graphical lessons. 

# 1 — copy the skeleton
cp -r topics/_template topics/rust
# 2 — say WHY you're learning it
$EDITOR topics/rust/MISSION.md
# 3 — add graphical lessons (NNNN-name.html)
# 4 — commit & push; the README catalog updates itself

Ask the Pi teach agent to scaffold the first lesson — it'll match the graphical, self-citing style of the Pi course.
