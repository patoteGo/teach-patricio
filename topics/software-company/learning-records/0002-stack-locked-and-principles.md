**TypeScript + React + Node + Supabase**, concretely realized as **Next.js
(App Router) + TypeScript + Node API routes + Supabase + Vercel + Tailwind**.

Two principles to steer every future lesson:

1. **Teach the most common stack deeply; pivot only on necessity.** The default
   is one well-known stack (Next.js/TS/Supabase). Learning a *different* tool
   is triggered by a real client requirement — and "learn a new tool fast for a
   client" is itself a named skill to teach, not a detour to avoid.
2. **She already has AI exposure** — she is currently studying LLMs, skills, the
   MCP concept, and prompting. So the AI track does **not** start at "what is an
   LLM." The gap to fill is applying AI **inside the dev workflow** (Cursor /
   Copilot in code, context, review, safety), not chat-only prompting.
