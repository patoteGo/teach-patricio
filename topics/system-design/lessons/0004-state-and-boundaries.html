2O que guarda estadoWhat holds state

Instância stateless serve qualquer requisição — qualquer nó serve qualquer pedido, então você escala só adicionando nós. Empurre estado para fora do compute, para um store. Sessão “sticky” (afinidade) é um cheiro: significa que o estado ainda mora no nó errado.A stateless instance serves any request — any node serves any request, so you scale just by adding nodes. Push state out of compute, into a store. “Sticky” sessions (affinity) are a smell: they mean state still lives on the wrong node.

Banco de dadosDatabase

Durável — a fonte da verdade. Sobrevive a restart; é onde o estado precisa estar correto.Durable — the source of truth. Survives restarts; where state must be correct.

Cache

Rápido e volátil — acelera a leitura. Se sumir, reconstrói a partir do banco; nunca é a verdade.Fast and volatile — speeds up reads. If it vanishes, rebuild from the DB; never the truth.

Fila de mensagensMessage queue

Guarda trabalho pendente e desacopla em tempo. Bufferiza picos, retenta, controla backpressure.Holds pending work and decouples in time. Buffers spikes, retries, applies backpressure.

Sessão / clienteSession / client

Identidade por requisição: store de sessão (Redis), cookie assinado ou token no cliente. Nunca dentro do nó.Per-request identity: a session store (Redis), signed cookie, or a client token. Never inside the node.

3Corte módulos profundos, não rasosCut deep modules, not shallow ones

Alta coesão, baixo acoplamento. Uma boa fronteira esconde um módulo profundo (Ousterhout): interface pequena e simples por cima de uma implementação grande e complexa. Módulos rasos (interface grande, implementação trivial) vazam complexidade e se multiplicam — cada um adiciona uma coisa a aprender e quase nada a esconder.High cohesion, low coupling. A good boundary hides a deep module (Ousterhout): a small, simple interface over a large, complex implementation. Shallow modules (big interface, trivial impl) leak complexity and proliferate — each one adds a thing to learn and hides almost nothing.

Profundo ✓Deep ✓

Interface estreita, implementação grande. Máximo escondido, mínimo exposto.Narrow interface, large implementation. Maximum hidden, minimum exposed.

Raso ✗Shallow ✗

Interface larga, implementação rasa. Complexidade vaza — e rasos proliferam.Wide interface, thin implementation. Complexity leaks — and shallow ones multiply.

4Síncrono vs assíncrono: acoplamento no tempoSynchronous vs asynchronous: coupling in time

Request/response é mais simples — mas acoplou caller e callee no tempo: se o callee cai ou demora, você cai. Eventos/filas desacoplam no tempo (consistência eventual, retries, backpressure) ao custo de complexidade. Síncrono quando você precisa da resposta agora; assíncrono quando pode tolerar atraso.Request/response is simpler — but it couples caller and callee in time: if the callee is down or slow, so are you. Events/queues decouple in time (eventual consistency, retries, backpressure) at the cost of complexity. Synchronous when you need the answer now; asynchronous when you can tolerate delay.

Síncrono (request/response)Synchronous (request/response)

Mais simples; acoplado no tempo. Use quando precisa da resposta agora.Simpler; coupled in time. Use when you need the answer now.

Assíncrono (eventos/filas)Asynchronous (events/queues)

Desacopla no tempo: retries, backpressure, consistência eventual. Custa idempotência e ordem.Decouples in time: retries, backpressure, eventual consistency. Costs idempotency and ordering.

🗣️ Nudge: Lei de Conway.Nudge: Conway's Law. A arquitetura tende a espelhar a estrutura de comunicação da organização. Desenhe fronteiras que um time consiga donar de ponta a ponta — senão a fronteira não vai durar. Architecture tends to mirror the org's communication structure. Draw boundaries a team can own end-to-end — otherwise the boundary won't last.
