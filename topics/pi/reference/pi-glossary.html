PiPi

NúcleoCore

O próprio harness minimalista de codificação no terminal — o programa hospedeiro que faz um loop de um modelo sobre um punhado de ferramentas de arquivo e shell. Não é uma IDE, não é um framework de agentes.The minimal terminal coding harness itself — the host program that loops a model over a handful of file/shell tools. Not an IDE, not an agent framework.

HarnessHarness

NúcleoCore

A camada que orquestra o loop modelo↔ferramenta e armazena a sessão. A identidade definidora do Pi: um hospedeiro enxuto que você estende, em vez de um app pesado que você configura.The layer that orchestrates the model↔tool loop and stores the session. Pi's defining identity: a thin host you extend, rather than a fat app you configure.

TurnoTurn

NúcleoCore

Uma resposta do modelo mais quaisquer chamadas de ferramenta que ela faça — o corpo do loop do agente. Os turnos se repetem até o modelo responder em texto puro e parar de chamar ferramentas.One model response plus any tool calls it makes — the body of the agent loop. Turns repeat until the model replies in plain text and stops calling tools.

Loop de agenteAgent loop

NúcleoCore

O ciclo de raciocínio: agent_start → turnos → agent_end → agent_settled. "Settled" significa que não resta nova tentativa automática, compaction nem follow-up.The reasoning cycle: agent_start → turns → agent_end → agent_settled. "Settled" means no auto-retry, compaction, or follow-up remains.

FerramentaTool

NúcleoCore

Uma capacidade que o modelo pode chamar. Nativas mais quaisquer registradas por extensões. O modelo decide quando chamá-las; o Pi decide como as executar.A capability the model can call. Built-ins plus any registered by extensions. The model decides when to call them; Pi decides how they run.

Ferramentas nativasBuilt-in tools

NúcleoCore

read, bash, edit, write (ativas por padrão) + grep, find, ls (opcionais). Restrinja o conjunto com --tools / --exclude-tools.read, bash, edit, write (on by default) + grep, find, ls (opt-in). Scope the set with --tools / --exclude-tools.

Mensagem de steeringSteering message

InterativoInteractive

Enfileirada com Enter enquanto o agente trabalha. Entregue após o turno atual do assistente terminar suas chamadas de ferramenta — permite redirecionar um loop vivo sem bloqueá-lo.Queued with Enter while the agent works. Delivered after the current assistant turn finishes its tool calls — lets you redirect a live loop without blocking it.

Mensagem de follow-upFollow-up message

InterativoInteractive

Enfileirada com Alt+Enter. Entregue somente depois que o agente termina todo o trabalho. Use para "e depois faça também X".Queued with Alt+Enter. Delivered only after the agent finishes all work. Use for "and then also do X."

Nível de pensamentoThinking level

InterativoInteractive

Profundidade de raciocínio do modelo: off · minimal · low · medium · high · xhigh · max. Shift+Tab alterna entre elas. A cor da borda do editor reflete o nível atual.Model reasoning depth: off · minimal · low · medium · high · xhigh · max. Shift+Tab cycles it. Editor border color reflects the current level.

/reload/reload

InterativoInteractive

Recarrega extensões, skills, prompts, temas e arquivos de contexto sem reiniciar a sessão. Seu loop de feedback ao criar personalizações.Reload extensions, skills, prompts, themes, and context files without restarting the session. Your feedback loop while authoring customizations.

Bash inlineInline bash

InterativoInteractive

!command executa e envia a saída ao modelo; !!command executa sem enviar. Seu shell, inline, a qualquer momento.!command runs and sends output to the model; !!command runs without sending. Your shell, inline, anytime.

@file@file

InterativoInteractive

Digite @ no editor para fazer busca fuzzy e anexar arquivos do projeto. Equivalente na CLI: pi @file.md "…".Type @ in the editor to fuzzy-search and attach project files. CLI equivalent: pi @file.md "…".

Editor externoExternal editor

InterativoInteractive

Ctrl+G abre externalEditor / $VISUAL / $EDITOR (ou nano) para prompts longos.Ctrl+G opens externalEditor / $VISUAL / $EDITOR (or nano) for long prompts.

SessãoSession

SessõesSessions

A conversa como um arquivo JSONL com estrutura de árvore (cada entrada tem id + parentId). Salvo automaticamente em ~/.pi/agent/sessions/ por diretório de trabalho.The conversation as a JSONL file with a tree structure (each entry has id + parentId). Auto-saved under ~/.pi/agent/sessions/ by working directory.

RamificaçãoBranching

SessõesSessions

Bifurcações de sessão in-place via a estrutura de árvore — um único arquivo contém todos os ramos. Sem "undo", apenas navegue até qualquer ponto anterior e continue.In-place session forks via the tree structure — one file holds every branch. No "undo", just navigate to any earlier point and continue.

/tree/tree

SessõesSessions

Navega a árvore da sessão; pule para qualquer ponto e continue trabalhando. Abra rápido com Esc Esc. Marque favoritos com Shift+L.Navigate the session tree; jump to any point and keep working. Open fast with Esc Esc. Label bookmarks with Shift+L.

/fork/fork

SessõesSessions

Cria um novo arquivo de sessão a partir de uma mensagem anterior do usuário no ramo ativo. Útil para "e se eu tivesse perguntado de outro jeito".Create a new session file from a previous user message on the active branch. Good for "what if I'd asked it differently".

/clone/clone

SessõesSessions

Duplica o ramo ativo atual num novo arquivo de sessão na posição atual, mantendo o histórico completo.Duplicate the current active branch into a new session file at the current position, keeping full history.

CompactionCompaction

SessõesSessions

Sumarização com perda das mensagens antigas para liberar contexto. O histórico completo nunca se perde — ele permanece no JSONL; revisite via /tree.Lossy summarization of older messages to free context. Full history is never lost — it stays in the JSONL; revisit via /tree.

/compact/compact

SessõesSessions

Dispara a compaction manualmente, com instruções personalizadas opcionais (/compact focus on recent changes). A auto-compaction está ativa por padrão.Trigger compaction manually, with optional custom instructions (/compact focus on recent changes). Auto-compaction is on by default.

ExtensãoExtension

PersonalizaçãoCustomization

Módulo TypeScript que estende o Pi: ferramentas, comandos, manipuladores de eventos e UI personalizados. Carregado via jiti — sem passo de compilação. A superfície de poder mais profunda.TypeScript module extending Pi: custom tools, commands, event handlers, UI. Loaded via jiti — no compile step. The deepest power surface.

SkillSkill

PersonalizaçãoCustomization

Pacote de capacidade sob demanda (SKILL.md) seguindo o padrão Agent Skills. Apenas a descrição está sempre no contexto — as instruções completas carregam sob demanda (progressive disclosure).On-demand capability package (SKILL.md) following the Agent Skills standard. Only the description is always in context — full instructions load on demand (progressive disclosure).

PersonalizaçãoCustomization

Pacote PiPi Package

Arquivos de contextoContext files

PersonalizaçãoCustomization

AGENTS.md (ou CLAUDE.md) carregado automaticamente na inicialização a partir dos diretórios global, pai e atual, e concatenado.AGENTS.md (or CLAUDE.md) auto-loaded at startup from global, parent, and current directories and concatenated.

Prompt de sistemaSystem prompt

PersonalizaçãoCustomization

Instruções base do modelo. Substitua via .pi/SYSTEM.md; anexe (não substitua) via APPEND_SYSTEM.md.Base model instructions. Replace via .pi/SYSTEM.md; append (don't replace) via APPEND_SYSTEM.md.

ModosModes
