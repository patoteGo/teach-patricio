3Fixação & atualizaçõesPinning & updates

Uma versão (@1.2.3) ou ref (@v1) fixa um pacote. Pacotes fixados são pulados por pi update --extensions / --all — eles não derivam. Para mover um pacote fixado, reinstale num novo ref.A version (@1.2.3) or ref (@v1) pins a package. Pinned packages are skipped by pi update --extensions / --all — they don't drift. To move a pinned package, re-install at a new ref.

📌 FixadoPinned @ref

Reproduzível. Atualizações o pulam, mas ainda reconciliam o clone para o ref configurado. Mova com pi install …@new-ref.Reproducible. Updates skip it, but still reconcile the clone to the configured ref. Move with pi install …@new-ref.

🌀 Flutuante (sem ref)Floating (no ref)

Mais recente. pi update --extensions o move para frente. Bom para experimentação, arriscado para trabalho em equipe.Latest. pi update --extensions moves it forward. Fine for experimentation, risky for teamwork.

Para setups compartilhados/em equipe: fixe. Um .pi/settings.json de projeto com packages fixados significa que cada colega de equipe tem as mesmas capacidades — o Pi auto-instala os faltantes na inicialização, após confiança.For shared/team setups: pin. A project .pi/settings.json with pinned packages means every teammate gets the same capabilities — Pi auto-installs missing ones on startup after trust.

4Criando o seuCreating your own

Adicione uma chave pi ao package.json (ou apenas use diretórios convencionais) e marque-o com pi-package. Esse é todo o passo de publicação.Add a pi key to package.json (or just use conventional dirs) and tag it pi-package. That's the whole publishing step. 

// package.json
{
  "name": "my-pi-toolkit",
  "keywords": ["pi-package"],
  "pi": {
    "extensions": ["./extensions"],
    "skills":     ["./skills"],
    "prompts":    ["./prompts"],
    "themes":     ["./themes"],
    "video": "https://…/demo.mp4"   # prévia opcional da galeria# optional gallery preview
  }
}

Sem manifesto? Auto-descoberta. Sem uma chave pi, o Pi carrega de extensions/ (.ts/.js), skills/, prompts/ (.md), themes/ (.json).No manifest? Auto-discover. Without a pi key, Pi loads from extensions/ (.ts/.js), skills/, prompts/ (.md), themes/ (.json).

Regra de deps: deps de runtime → dependencies. Bibliotecas centrais do Pi (pi-ai, pi-tui, typebox…) → peerDependencies: "*", não empacote.Deps rule: runtime deps → dependencies. Core Pi libs (pi-ai, pi-tui, typebox…) → peerDependencies: "*", don't bundle.

5Segurança — leia duas vezesSecurity — read this twice

Pacotes do Pi rodam com seu acesso total ao sistema. Extensões executam código arbitrário; skills podem instruir o modelo a realizar qualquer ação — incluindo executar binários. Revise o código-fonte antes de instalar qualquer coisa de terceiros. Mesma higiene que npm install, mas o raio de explosão inclui “o modelo seguindo instruções não confiáveis.”Pi packages run with your full system access. Extensions execute arbitrary code; skills can instruct the model to perform any action — including running executables. Review the source before installing anything third-party. Same hygiene as npm install, but the blast radius includes "the model following untrusted instructions."
