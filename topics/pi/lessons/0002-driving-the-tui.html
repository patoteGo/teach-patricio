3Steering — o superpoder do power-userSteering — the power-user superpower

Esta é a maior alavanca de produtividade do Pi. Com o agente no meio do loop, você tem três formas de intervir. Escolha a certa e nunca fica parado.This is the single biggest productivity lever in Pi. While the agent is mid-loop, you have three ways to intervene. Pick the right one and you never sit idle.

↩️

SteeringSteering

Enter durante o trabalhoEnter while working

Entregue após as chamadas de ferramenta do turno atual terminarem. "Na verdade, confira os testes também."Delivered after the current turn's tool calls finish. "Actually, also check the tests."

📋

Follow-upFollow-up

Alt+EnterAlt+Enter

Entregue só depois que o agente terminar tudo. "Agora faça a documentação também."Delivered only after the agent is fully done. "Now do the docs too."

✋

AbortarAbort

EscEsc

Para a execução; as msgs enfileiradas voltam ao editor (Alt+↑). Nada perdido.Stops the run; queued msgs return to the editor (Alt+↑). Nothing lost.

Modelo mental: o steering edita o plano da execução atual; o follow-up enfileira a próxima execução. A entrega padrão é uma de cada vez (cada uma espera por uma resposta) — mude para lote nas configurações via steeringMode / followUpMode = "all".Mental model: steering edits the current run's plan; follow-up queues the next run. Default delivery is one-at-a-time (each waits for a reply) — switch to batch in settings via steeringMode / followUpMode = "all".

4Leia seu orçamentoRead your budget

O rodapé é seu painel. Os dois números que mais importam: contexto % (quão cheia está a janela) e custo.The footer is your dashboard. The two numbers that matter most: context % (how full the window is) and cost.

↑ 12.4k entradainput ↓ 3.1k saídaoutput R 8.0k leitura de cachecache read W 2.2k escrita de cachecache write CH 87% acerto de cachecache hit $ 0.04 _CTX 18%

Contexto 18% — verde. Passando de ~80%, espere a compactação automática (Lição 3) entrar em ação.Context 18% — green. Past ~80%, expect auto-compaction (Lesson 3) to kick in.

Acerto de cache (CH) = dinheiro de graça. Uma alta proporção de leitura de cache significa que o Pi está reaproveitando tokens em cache (baratos) em vez de reenviar (preço cheio). Se o CH cai, você pode estar agitando o contexto à toa — um sinal para compactar ou iniciar uma sessão nova.Cache hit rate (CH) = free money. A high cache-read ratio means Pi is reusing prompt-cached tokens (cheap) instead of re-sending (full price). If CH drops, you may be churning context unnecessarily — a signal to compact or start a fresh session.
