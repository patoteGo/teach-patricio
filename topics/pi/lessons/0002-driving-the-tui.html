1Anatomy of the screen

Four regions, top to bottom. Knowing what each shows is the difference between guessing and reading Pi.

① Header

Loaded AGENTS.md, active skills, extensions, prompt templates. Your "what's wired up" glance. /hotkeys lives here.

② Messages

Your prompt, the model's reply, every tool call + result. Collapse noise with Ctrl+O (tools) and Ctrl+T (thinking).

③ Editor

Where you type. Border color = thinking level. @ files, Tab complete, Ctrl+G for a real editor.

④ Footer

The dashboard: cwd, session name, token/cache/cost, context %, current model. Your budget readout.

Source: Pi docs · Interactive Mode.

2The power keys

You don't need all of them today. Memorize these six groups and Pi stops feeling like a chat and starts feeling like a cockpit.

🎛️ Models & thinking

Ctrl+L model picker · Ctrl+P / ⇧Ctrl+P cycle scoped models · Shift+Tab cycle thinking level

📣 Steering the loop

Enter queue steering msg · Alt+Enter queue follow-up · Alt+↑ pull a queued msg back · Esc abort

🧹 Taming the output

Ctrl+O collapse/expand tool output · Ctrl+T collapse/expand thinking · Ctrl+X copy last reply

🌲 Sessions

Esc Esc open /tree · then ⌃←/⌃→ jump branches · Shift+L label a bookmark

✍️ Editor craft

Shift+Enter newline · Ctrl+G external editor · Ctrl+V paste image/text · !cmd inline bash

🛑 Exit & clear

Ctrl+C clear editor · Ctrl+C Ctrl+C quit · Ctrl+D exit when empty

Full list: Pi docs · Keyboard Shortcuts (or /hotkeys in-app). Customize via ~/.pi/agent/keybindings.json.

3Steering — the power-user superpower

This is the single biggest productivity lever in Pi. While the agent is mid-loop, you have three ways to intervene. Pick the right one and you never sit idle.

↩️

Steering

Enter while working

Delivered after the current turn's tool calls finish. "Actually, also check the tests."

📋

Follow-up

Alt+Enter

Delivered only after the agent is fully done. "Now do the docs too."

✋

Abort

Esc

Stops the run; queued msgs return to the editor (Alt+↑). Nothing lost.

Mental model: steering edits the current run's plan; follow-up queues the next run. Default delivery is one-at-a-time (each waits for a reply) — switch to batch in settings via steeringMode / followUpMode = "all".

Source: Pi docs · Message Queue.

4Read your budget

The footer is your dashboard. The two numbers that matter most: context % (how full the window is) and cost.

↑ 12.4k input ↓ 3.1k output R 8.0k cache read W 2.2k cache write CH 87% cache hit $ 0.04 _CTX 18%

Context 18% — green. Past ~80%, expect auto-compaction (Lesson 3) to kick in.

Cache hit rate (CH) = free money. A high cache-read ratio means Pi is reusing prompt-cached tokens (cheap) instead of re-sending (full price). If CH drops, you may be churning context unnecessarily — a signal to compact or start a fresh session.

5Commands you'll type daily

Type / to open the command menu. These eight cover 90% of daily use.

/model

Switch models (also Ctrl+L).

/compact [prompt]

Free context; optional focus instructions.

/tree

Navigate & branch the session.

/new · /resume · /fork

Session lifecycle.

/copy · /export · /share

Get data out (clipboard, HTML/JSONL, gist).

/reload

Hot-reload skills/extensions/themes.

/settings

Thinking, theme, delivery, transport.

/session

See ID, tokens, cost for this session.
