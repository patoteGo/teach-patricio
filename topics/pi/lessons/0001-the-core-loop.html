1O que o Pi realmente éWhat Pi actually is

Uma frase para ancorar tudo: Pi é um harness minimalista de terminal que faz um loop de um modelo sobre um punhado de ferramentas de arquivo e shell. Não é, de propósito, uma IDE, nem um framework de agentes, nem um app de chat.One sentence to anchor everything: Pi is a minimal terminal harness that loops a model over a handful of file-and-shell tools. It is deliberately not an IDE, not an agent framework, not a chat app.

Fonte:Source: documentos do Pi — Visão geralPi docs — Overview · “Por padrão, o pi dá ao modelo quatro ferramentas: read, write, edit e bash.”“By default, pi gives the model four tools: read, write, edit, and bash.”

A mudança de enquadramento: o Pi é o host. O modelo é o cérebro, as quatro ferramentas são suas mãos, o JSONL da sessão é sua memória. O Pi em si quase não tem recursos de propósito — você os parafusa. Tudo o que “falta” (sub-agentes, plan mode, permissões…) é uma escolha, não um esquecimento.The reframe: Pi is the host. The model is the brain, the four tools are its hands, the session JSONL is its memory. Pi itself owns almost no features on purpose — you bolt those on. Everything “missing” (sub-agents, plan mode, permissions…) is a choice, not an oversight.

3O loop de turnoThe turn loop

Esta é a figura mais importante de todo o curso. Um turno é “modelo raciocina → talvez chame ferramentas → vê resultados → raciocina de novo”. O loop se repete até o modelo parar de chamar ferramentas e responder.This is the single most important picture in the whole course. A turn is “model reasons → maybe calls tools → sees results → reasons again”. The loop repeats until the model stops calling tools and replies.

  1. Você envia o prompt. Digite um pedido + referências @file opcionais.You prompt. Type a request + optional @file refs. → before_agent_start
  2. O modelo raciocina. Ele pensa (o bloco de thinking recolhível) e emite uma resposta — texto, ou chamadas de ferramenta.Model reasons. It thinks (the collapsible thinking block) and emits a response — either text, or tool calls.
  3. Ele chama ferramentas. p.ex. read em três arquivos, depois bash npm test.It calls tools. e.g. read three files, then bash npm test. → tool_call
  4. O Pi as executa. O harness roda cada chamada e devolve os resultados — não o runtime do modelo, o do Pi.Pi runs them. The harness executes each call and feeds results back — not the model's runtime, Pi's.
  5. Os resultados voltam. O loop salta ao passo 2 com novo contexto. Repita até o modelo responder em texto puro.Results return. The loop jumps to step 2 with new context. Repeat until the model replies in plain text. → turn_end / agent_settled

Insight de poder: enquanto o loop roda, você não fica preso esperando. Pressione Enter para enfileirar uma mensagem de steering (entregue após o lote de ferramentas atual) ou Alt+Enter para um follow-up (entregue após todo o trabalho terminar). Você dirige um loop vivo — não o bloqueia.Power insight: while the loop runs you are not stuck waiting. Press Enter to queue a steering message (delivered after the current tool batch) or Alt+Enter for a follow-up (delivered after all work finishes). You steer a live loop — you don't block it.

O número que importa: cada 🔧 é uma viagem de ida e volta que consome contexto + tokens. Sessões longas enchem a janela — é exatamente o que a compaction (uma lição posterior) existe para gerenciar. O loop inteiro é registrado num arquivo JSONL ramificado que você pode rebobinar a qualquer hora com /tree.The number that matters: each 🔧 is a round-trip that consumes context + tokens. Long sessions fill the window — that's exactly what compaction (a later lesson) exists to manage. The whole loop is logged to one branching JSONL file you can rewind anytime with /tree.

5O que o Pi omite de propósitoWhat Pi deliberately omits

Ler esta grade é o que transforma “por que o Pi não tem X?” em “ah, X é uma escolha que eu faço.” Cada item riscado tem uma alternativa Pi-nativa explícita.Reading this grid is what turns “why doesn't Pi have X?” into “ah, X is a choice I make.” Every crossed-out item has an explicit Pi-native alternative.

🚫 Sem servidores MCP🚫 No MCP servers

Construa uma ferramenta CLI com um README (uma skill), ou adicione MCP via extensão.Build a CLI tool with a README (a skill), or add MCP via an extension.

🚫 Sem sub-agentes🚫 No sub-agents

Spawne instâncias do Pi no tmux, construa as suas com extensões, ou instale um package.Spawn Pi instances in tmux, build your own with extensions, or install a package.

🚫 Sem popups de permissão🚫 No permission popups

Rode num container, ou construa um fluxo de confirmação com uma extensão.Run in a container, or build a confirmation flow with an extension.

🚫 Sem plan mode · sem to-dos🚫 No plan mode · no to-dos

Escreva planos/TODOs num arquivo — ou, de novo, uma extensão.Write plans/TODOs to a file — or, again, an extension.

🚫 Sem bash em segundo plano🚫 No background bash

Use tmux. Observabilidade total, interação direta, sem mágica.Use tmux. Full observability, direct interaction, no magic.
