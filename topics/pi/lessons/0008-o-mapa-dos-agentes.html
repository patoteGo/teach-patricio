A ideia central: o LLM não é “o aplicativo inteiro”. Ele é uma peça dentro do agente; o agente roda dentro de um harness; skills orientam o agente; ferramentas realizam ações; MCP pode trazer algumas dessas capacidades por uma conexão padronizada.The core idea: the LLM isn't “the whole app”. It's one piece inside the agent; the agent runs inside a harness; skills guide the agent; tools carry out actions; MCP can bring some of those capabilities through a standardized connection.

Os nomes não são perfeitamente padronizados. Produtos inteiros são frequentemente chamados de “agentes”. Aqui usamos agente no sentido arquitetural — LLM dirigindo passos e ferramentas em loop — e harness para o software hospedeiro. A própria documentação do Pi o chama de minimal terminal coding harness.The names aren't perfectly standardized. Whole products are often called “agents”. Here we use agent in the architectural sense — an LLM driving steps and tools in a loop — and harness for the host software. Pi's own docs call it a minimal terminal coding harness.

2As seis peças, sem neblinaThe six pieces, no fog

Para cada peça: a pergunta que ela responde, o que ela é e o que ela definitivamente não é.For each piece: the question it answers, what it is, and what it definitely isn't.

1

LLM · o modeloLLM · the model

“Qual saída faz sentido agora?”“Which output makes sense right now?”

Um grande modelo de linguagem recebe contexto e gera uma sequência de tokens. A saída pode ser texto normal ou uma estrutura pedindo o uso de uma ferramenta.A large language model takes context and generates a sequence of tokens. The output can be plain text or a structure requesting the use of a tool.

ÉIs
o motor de linguagem e decisão.the language and decision engine.
Não éIsn't
a janela de chat, o shell ou o executor.the chat window, the shell, or the executor.
ExemploExample
Claude, GPT, Gemini; o modelo selecionado no Pi.Claude, GPT, Gemini; the model selected in Pi.
2

Agente · o loop orientado a objetivoAgent · the goal-driven loop

“Qual é o próximo passo para concluir a tarefa?”“What's the next step to finish the task?”

Um sistema no qual o LLM escolhe dinamicamente passos e ferramentas, observa resultados reais e decide de novo até concluir, parar ou pedir ajuda.A system in which the LLM dynamically picks steps and tools, observes real results, and decides again until it finishes, stops, or asks for help.

ÉIs
LLM + instruções + ferramentas + loop + limites.LLM + instructions + tools + loop + limits.
Não éIsn't
sinônimo de uma única chamada ao modelo.synonymous with a single call to the model.
ExemploExample
um coding agent que lê, edita, testa e corrige.a coding agent that reads, edits, tests, and fixes.
3

Harness · o hospedeiroHarness · the host

“Quem põe o agente para rodar de verdade?”“Who actually gets the agent running?”

O aplicativo/runtime ao redor do agente. Monta o contexto, chama o provedor do LLM, apresenta e executa ferramentas, guarda a sessão e oferece interface, eventos e controles.The application/runtime around the agent. It assembles the context, calls the LLM provider, presents and runs tools, stores the session, and offers an interface, events, and controls.

ÉIs
a infraestrutura operacional do agente.the agent's operational infrastructure.
Não éIsn't
o modelo nem uma capacidade específica.the model or any specific capability.
ExemploExample
Pi; em uso comum, Claude Code ou Codex CLI.Pi; in common use, Claude Code or Codex CLI.
4

Ferramenta · uma ação chamávelTool · a callable action

“Que ação concreta o sistema pode executar?”“What concrete action can the system perform?”

Uma função nomeada, descrita e normalmente tipada por um schema. O LLM pede a chamada; o runtime valida e executa; o resultado volta ao contexto.A named function, described and usually typed by a schema. The LLM requests the call; the runtime validates and runs it; the result returns to the context.

ÉIs
um verbo operacional com entrada e saída.an operational verb with input and output.
Não éIsn't
o raciocínio que escolhe quando usá-la.the reasoning that chooses when to use it.
ExemploExample
read, edit, bash, buscar_issue.read, edit, bash, buscar_issue.
5

Skill · um playbook sob demandaSkill · an on-demand playbook

“Como fazer este tipo de trabalho direito?”“How do I do this kind of work well?”

Uma pasta com SKILL.md: instruções, conhecimento procedural e, opcionalmente, scripts e referências. O agente pode carregar o conteúdo completo quando a tarefa é relevante.A folder with a SKILL.md: instructions, procedural knowledge, and optionally scripts and references. The agent can load the full content when the task is relevant.

ÉIs
know-how portátil e versionável.portable, versionable know-how.
Não éIsn't
uma ação executada sozinha.an action that runs on its own.
ExemploExample
um playbook de diagnóstico de bugs.a bug-diagnosis playbook.
6

MCP · um protocolo de conexãoMCP · a connection protocol

“Como clientes descobrem e usam integrações?”“How do clients discover and use integrations?”

O Model Context Protocol padroniza a comunicação entre clientes e servidores locais ou remotos; a aplicação host cria e coordena esses clientes. Servidores podem expor ferramentas, recursos e prompts.The Model Context Protocol standardizes communication between clients and local or remote servers; the host application creates and coordinates those clients. Servers can expose tools, resources, and prompts.

ÉIs
um contrato de interoperabilidade cliente-servidor.a client-server interoperability contract.
Não éIsn't
um LLM, agente, skill ou ferramenta única.an LLM, agent, skill, or single tool.
ExemploExample
um servidor Sentry expondo get_issue.a Sentry server exposing get_issue.

3Um bug, seis papéisOne bug, six roles

Pedido: “O checkout quebrou. Encontre a causa, corrija e rode os testes.” Acompanhe quem faz cada coisa.The request: “Checkout broke. Find the cause, fix it, and run the tests.” Follow who does each thing.

  1. 1
    Harness

    O Pi recebe seu pedido, monta o contexto — prompt do sistema, histórico, AGENTS.md, nome + descrição das skills e schemas das ferramentas — e envia tudo ao LLM escolhido.Pi receives your request, assembles the context — system prompt, history, AGENTS.md, skill names + descriptions, and tool schemas — and sends it all to the chosen LLM.

  2. 2
    LLM

    O modelo reconhece uma tarefa de diagnóstico. Em vez de apenas responder com texto, pede para ler a skill relevante: read(.../diagnosing-bugs/SKILL.md).The model recognizes a diagnosis task. Instead of just replying with text, it asks to read the relevant skill: read(.../diagnosing-bugs/SKILL.md).

  3. 3
    Skill

    O playbook entra no contexto: reproduza primeiro, trace os chamadores, corrija a causa compartilhada e deixe uma verificação executável. A skill ensinou o método; ainda não tocou no código.The playbook enters the context: reproduce first, trace the callers, fix the shared cause, and leave an executable check. The skill taught the method; it hasn't touched the code yet.

  4. 4
    AgenteAgent

    Guiado pelo objetivo e pelo playbook, o loop escolhe o próximo passo: ler checkout.ts e procurar todos os chamadores da função suspeita.Guided by the goal and the playbook, the loop picks the next step: read checkout.ts and find every caller of the suspect function.

  5. 5
    Ferramenta + harnessTool + harness

    O LLM emite a chamada read; o harness valida e executa a função. O conteúdo real do arquivo volta ao modelo. A frase “o LLM leu o arquivo” é um atalho: tecnicamente, ele pediu e o harness executou.The LLM emits the read call; the harness validates and runs the function. The real file content returns to the model. The phrase “the LLM read the file” is a shortcut: technically, it asked and the harness ran it.

  6. 6
    Agente em loopAgent in a loop

    Com o resultado, o LLM decide novamente: edit para a correção; depois bash("npm test"). Se o teste falha, o resultado alimenta outra volta. Se passa, o modelo para de chamar ferramentas e responde.With the result, the LLM decides again: edit for the fix; then bash("npm test"). If the test fails, the result feeds another lap. If it passes, the model stops calling tools and replies.

  7. 7
    MCP · ramo opcionalMCP · optional branch

    Se o erro estiver no Sentry e o harness tiver uma integração MCP, um servidor pode expor sentry_get_issue. Para o agente, ela aparece como outra ferramenta; MCP foi o caminho que a tornou descobrível e chamável. O Pi puro não inclui MCP: use uma extensão, package ou CLI via bash quando fizer sentido.If the error is in Sentry and the harness has an MCP integration, a server can expose sentry_get_issue. To the agent it shows up as just another tool; MCP was the path that made it discoverable and callable. Plain Pi doesn't include MCP: use an extension, package, or CLI via bash when it makes sense.

O detalhe que evita antropomorfismo: “o agente decidiu” quer dizer que, dentro do loop, o LLM gerou a próxima ação a partir do contexto; o harness aplicou regras, executou a ação e trouxe feedback do ambiente.The detail that avoids anthropomorphism: “the agent decided” means that, within the loop, the LLM generated the next action from the context; the harness applied rules, ran the action, and brought back feedback from the environment.

MCP não significa “ferramentas remotas”. Um servidor MCP pode rodar localmente via stdio ou remotamente via HTTP. E “ser MCP” não torna uma integração segura por mágica: autenticação, autorização, aprovações e limites continuam sendo responsabilidades do host e do sistema conectado.MCP doesn't mean “remote tools”. An MCP server can run locally over stdio or remotely over HTTP. And “being MCP” doesn't make an integration secure by magic: authentication, authorization, approvals, and limits remain the responsibility of the host and the connected system.

A arquitetura oficial define um host que cria um cliente por servidor; servidores podem expor tools, resources e prompts. 5O teste da subtraçãoThe subtraction test

Ainda confuso? Remova uma peça mentalmente. O que deixa de existir revela a responsabilidade dela.Still confused? Mentally remove one piece. What ceases to exist reveals its responsibility.

Sem LLM →Without an LLM →

Pode haver automação determinística, mas não a decisão linguística e flexível descrita aqui.There can be deterministic automation, but not the flexible, language-driven decision-making described here.

Sem loop de agente →Without an agent loop →

Ainda existe uma chamada ao LLM, porém não a sequência autônoma de observar, decidir, agir e repetir.There's still a call to the LLM, but not the autonomous sequence of observe, decide, act, and repeat.

Sem harness →Without a harness →

O modelo/API continua existindo, mas alguém precisa montar contexto, executar chamadas, guardar estado e oferecer uma interface.The model/API still exists, but someone has to assemble context, run calls, store state, and offer an interface.

Sem ferramentas →Without tools →

O sistema pode raciocinar e escrever, mas não lê seu disco, roda testes ou altera sistemas externos.The system can reason and write, but it can't read your disk, run tests, or change external systems.

Sem skills →Without skills →

O agente ainda age com conhecimento geral, mas perde o playbook especializado, portátil e carregado sob demanda.The agent still acts on general knowledge, but loses the specialized, portable, on-demand playbook.

Sem MCP →Without MCP →

Ferramentas nativas, extensões e CLIs continuam funcionando; perde-se apenas esse padrão de interoperabilidade.Native tools, extensions, and CLIs keep working; you only lose this interoperability standard.

Qual peça você precisa criar?Which piece do you need to create?

  • Precisa de uma ação nova e concreta?Need a new, concrete action?ferramentatool
  • Precisa ensinar um processo repetível?Need to teach a repeatable process?skill
  • Precisa de decisões em vários passos?Need multi-step decisions?agenteagent
  • Precisa de UI, sessão e execução?Need UI, session, and execution?harness
  • Precisa trocar a capacidade de raciocínio?Need to swap the reasoning capability?LLM
  • Precisa integrar vários clientes pelo mesmo padrão?Need to integrate several clients under one standard?MCP

No Pi, suba a escada mais curta: use as ferramentas existentes; depois uma skill; depois uma extensão ou ferramenta personalizada. Adote MCP quando a interoperabilidade com o ecossistema compensar cliente, servidor, contexto e superfície de segurança adicionais.In Pi, climb the shortest ladder: use the existing tools; then a skill; then an extension or custom tool. Adopt MCP when ecosystem interoperability justifies the extra client, server, context, and security surface.
