⬡ Lesson 03 · Sessions

One file,
many branches,
nothing lost.

A Pi session isn't a linear chat log — it's a tree in a single JSONL file. Master branching and compaction and long sessions stop being scary: you can rewind, fork, and shrink context without ever deleting your work.

↑ Mission · prev: Lesson 2 · Driving the TUI · ref: Glossary

1A session is a tree, not a log

Every entry has an id and a parentId. Your current position is the active leaf. There's no "undo" — there's only navigate. One file holds every branch you ever explored.

The reframe: "go back and try something else" doesn't discard anything — it grows a new branch. The old path stays in the same JSONL forever. You're not editing history; you're navigating a tree.

Source: Pi docs · Sessions · file format in session-format.

2/tree — navigate in place

Open it with Esc Esc. Jump to any earlier point and continue — same file, new branch. What you select decides what happens next.

Select a user msg

Leaf → its parent; the message text drops into the editor. Edit & resubmit → spawns a new branch.

Select an assistant/tool msg

Leaf → that entry; editor stays empty. You simply continue from that point in history.

Select the root

Resets to an empty conversation; the original prompt returns to the editor. A clean restart, same file.

Tree controls

↑↓ move · ←→ page · Enter select · Esc cancel

Ctrl+←/→ (or Alt) fold/unfold & jump between branch segments

Shift+L set/clear a bookmark label · Shift+T toggle timestamps

Ctrl+O cycle filter: default → no-tools → user-only → labeled-only → all

Tip: bookmark turning points with Shift+L, then filter to labeled-only to fly through long sessions. Set the default filter via treeFilterMode in settings.

3/tree vs /fork vs /clone

Three ways to "go back." The difference is simple: same file or new file?

🌳

/tree

Same file

Full tree view

Explore alternatives in place

Optional branch summary

⑂

/fork

New file

Picks a past user message

"What if I'd asked differently?"

No summary

⧉

/clone

New file

Duplicates active branch

Snapshot before a risky change

No summary

Rule of thumb: /tree keeps alternatives together; /fork & /clone split them into separate files. Use /clone as a cheap "save point" before letting Pi do something destructive.

4Session control from the shell

You don't have to be inside Pi to manage sessions. These flags run at startup. 

# resume / pick
pi -c                      # continue most recent session
pi -r                      # browse & select (same as /resume)
pi --session <path|id>     # jump to a specific file or partial UUID
pi --fork <path|id>        # fork an existing session into a new file

# name & ephemeral
pi --name "Refactor auth"   # named = findable later (also /name)
pi --no-session            # ephemeral: don't save anything

Inside the /resume picker

Ctrl+P toggle path · Ctrl+S sort mode · Ctrl+N named-only filter · Ctrl+R rename · Ctrl+D delete (uses the trash CLI if available — recoverable).

Source: Pi docs · Sessions.

5Compaction — when the window fills up

Long sessions exhaust the context window. Compaction summarizes older messages and keeps recent ones. It's lossy — but the full history is never deleted; it lives on in the JSONL.

When it fires (auto, on by default):

reserve defaults to 16,384 tokens (room for the reply). It keeps 20,000 recent tokens (keepRecentTokens), summarizes the rest.

Manual control: /compact now, or /compact focus on the auth refactor to steer the summary. Auto fires on overflow (recovers + retries) or near the limit (proactive).

It never cuts at a tool result — results stay glued to their tool call. One giant turn over budget? Pi makes a "split turn" with two merged summaries.

Source: Pi docs · Compaction · tune via compaction.{enabled, reserveTokens, keepRecentTokens}.

6Branch summaries & the knobs

When you /tree away from a branch, Pi offers to summarize the path you're leaving and inject it at the new spot — so context survives the jump. Same engine as compaction; tracks files cumulatively. 

// ~/.pi/agent/settings.json  (or .pi/settings.json)
{
  "compaction": {
    "enabled": true,            // auto-compaction on/off
    "reserveTokens": 16384,     // room left for the reply
    "keepRecentTokens": 20000   // how much recent context survives
  },
  "treeFilterMode": "labeled-only"  // your default /tree filter
}

Power move: set treeFilterMode: "labeled-only" and label your turning points (Shift+L). Long sessions become a handful of bookmarks you can fly between — no scrolling through tool spam.
