# Tooling Resources

## Knowledge

- [Vim User Manual — The first steps in Vim](https://vimhelp.org/usr_02.txt.html)
  Official introduction to modes, `i`, `<Esc>`, `hjkl`, deletion, undo, saving, and quitting. Primary source for the first lesson.
- [Vim User Manual — Moving around](https://vimhelp.org/usr_03.txt.html)
  Official guide to word and line motions such as `w`, `b`, `0`, and `$`. Use after the core mode loop is comfortable.
- [VimTutor — official Vim repository](https://github.com/vim/vim/tree/master/runtime/tutor)
  The practice lesson shipped with Vim. Run `vimtutor` for guided, hands-on repetition without configuring anything.

## Wisdom (Communities)

- [Vi and Vim Stack Exchange](https://vi.stackexchange.com/)
  Moderated Q&A for concrete editing workflows and troubleshooting. Search existing answers before adding configuration.

## Gaps

- Add workflow-specific sources only after the learner chooses where Vim motions will be used daily (terminal Vim, IDE extension, or shell tools).
