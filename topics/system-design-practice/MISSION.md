# Mission: System Design Interview Dojo

## Why

Transform system design from a knowledge test into a **visible performance**: clarify the problem, draw a useful architecture, and narrate tradeoffs without freezing. Practice the real interview medium—marker/whiteboard plus speech—not just reading solutions.

## Success looks like

- Start any prompt with a crisp requirements → estimate → architecture loop.
- Draw a legible first-pass diagram in 5 minutes while explaining each box.
- Narrate one request path, one failure mode, and two tradeoffs in plain language.
- Review a recording and name one concrete improvement for the next round.

## Constraints

- Senior fullstack baseline; no introductory CS lectures.
- Short, repeatable drills: 25–35 minutes, 3 times per week.
- Practice on paper, a whiteboard, or a blank drawing app; no polished diagrams.
- Portuguese default, English available when useful for interview vocabulary.

## Out of scope

- Memorizing “perfect” architectures.
- Building production systems or collecting vendor-specific trivia.
- Replacing the System Design fundamentals topic; this topic is deliberate practice.
