2O coração: outbox + workerThe core: outbox + worker

O padrão-chave deste nível: não chame o webhook síncrono. Grave o evento numa tabela “outbox”; um worker puxa e entrega.The key pattern at this level: don't call the webhook synchronously. Write the event to an “outbox” table; a worker pulls and delivers.

Narração: “Quando o status muda, gravo uma linha no outbox: (event_id, customer, payload, status=pending, attempts=0). Um worker puxa os pending, faz um POST assinado para a URL do cliente. Em sucesso, marca delivered. Em falha, incrementa tentativas com backoff; após N, manda pra dead-letter e alerta.”Narration: “When the status changes, I write a row to the outbox: (event_id, customer, payload, status=pending, attempts=0). A worker pulls pending rows, makes a signed POST to the customer's URL. On success, mark delivered. On failure, increment attempts with backoff; after N, send to dead-letter and alert.”

Idempotência = a frase que abre portas:Idempotency = the phrase that opens doors: “Assino o payload com HMAC e incluo um event_id; o cliente deve ser idempotente — se receber o mesmo event_id de novo, ignora.” Dizer isso demonstra maturidade sênior.“I sign the payload with HMAC and include an event_id; the customer must be idempotent — if it sees the same event_id again, it ignores it.” Saying that signals senior maturity.
