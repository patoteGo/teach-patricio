# Teaching Notes — System Design Interview Dojo

## Learner profile

- Experienced developer; knows the fundamentals topic but needs fluency under interview conditions.
- Main difficulty: drawing and talking at the same time.

## Practice loop

1. Pick one prompt and state assumptions aloud.
2. Draw only boxes, arrows, and labels; narrate while drawing.
3. Time-box the design, then explain one deep dive and one tradeoff.
4. Record audio/video when possible; review one behavior, not everything.
5. Repeat the same prompt after 48 hours from memory.

## Session log

- Session 1: created the dojo as a separate practice track. First lesson teaches the draw-and-talk loop and a 25-minute drill.
